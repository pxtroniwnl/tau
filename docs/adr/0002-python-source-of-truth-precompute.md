# ADR-0002: Python as source of truth, with static precomputation

- Status: accepted
- Date: 2026-11-22

## Context
- The animation needs physics at 60 fps in the browser; an HTTP call per frame is not an option.
- A serverless backend has cold starts.
- The paper needs a single reference implementation.

## Decision
1. **Python is the source of truth.** The frontend carries a minimal TS mirror of only what runs per frame. Its tests must match `data/golden/golden.json`, which Python generates.
2. **Blackbody color and the disk profile** reach the shader as LUT textures generated by Python, so the shader does not reimplement those formulas.
3. **Everything standard is precomputed** in CI and served as static files from the CDN. The API (FastAPI on Vercel) only handles custom parameters; if it fails or is slow, the UI shows the precomputed value.

## Consequences
- Controlled duplication between Python and TS, verified on every CI run.
- Cold starts never block the experience.
- Generated artifacts are committed, so the repo is somewhat larger.
