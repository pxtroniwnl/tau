# Contributing

Welcome! Getting started:

1. Install [uv](https://docs.astral.sh/uv/) and Node.js 24+.
2. Run `cd backend && uv sync`, then `cd ../frontend && npm ci`.
3. Read [AGENTS.md](AGENTS.md). It holds **all** project rules and conventions: traceability, documentation duty, architecture changes, branches, commits, PRs and checks.
4. Pick or open an issue, branch off `main`, and open a PR using the template.

Found a wrong catalog value? Open a "Data correction" issue with its primary source (DOI/arXiv).
